`docker build` on the generated Dockerfile, starts the container with `DATABASE_URL` set, and checks
`/healthz` and `/readyz` over HTTP and that the image declares a non-root user.

## Quality control (DMAIC)

| Phase | This repository |
|---|---|
| Define | New services are set up by hand, so CI files, Dockerfiles, catalog entries and docs drift from team to team; this affects platform teams and developers starting a service. M1 counts when one Backstage template generates a Node.js, Python or Go service (with or without a database) that passes Backstage's catalog validation and its own tests, with SHA-pinned actions and digest-pinned non-root images, and form input is validated before anything is written ([RFC 0001](../rfc/0001-design.md)). |
| Measure | `make test` (run twice after the final change), strict `tsc`, `npm audit` and `make measure` on an Intel Core i7-13700H with Windows 11, plus one local run of the image build and probe on 2026-10-07. 57 tests passed, 0 failed; form-to-passing-tests took 323 to 344 ms for Node.js, 2,182 to 3,199 ms for Python and 4,202 to 4,243 ms for Go; all three images answered `/healthz` and `/readyz` as a non-root user. |
| Analyze | All six combinations generate, validate and pass their own tests, and rendering takes tens of milliseconds, so the rest of the time is each service's own test run. No defects recorded. Time-to-first-deploy before and after is not measured yet (M3). |
| Improve | No defect needed a change in M1. |
| Control | The `ci` workflow's `build` job runs `make ci` (strict `tsc` and the 57 tests, including the generated services' own suites), posts failing output as an annotation, prints `make measure` to the job summary and runs `make audit` (`npm audit`); the `generated-images` matrix job builds, runs and probes the image of every language and checks it declares a user. In the code, Ajv applies strict patterns to every form value (ADR 0003), undefined template variables are errors, and the renderer refuses empty, absolute or escaping paths and double writes. |
