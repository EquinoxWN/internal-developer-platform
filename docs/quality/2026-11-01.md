# Quality check against the 10 rules (2026-11-01)

Run on Windows 11 (Intel Core i7-13700H) with Node.js 24.19, Python 3.14 and Go 1.26.10 for the
generated services. Mutations were applied one at a time by a script that restores each file.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | fixed | External calls are subprocesses only (`src/generated.ts`). Running generated tests had a 120 s timeout, but its error (spawn failure or timeout) was dropped from the output; it is now appended. The toolchain probe `available()` had no timeout; it now has 30 s. `idp validate-catalog` on a missing file crashed with a stack trace; it now prints `error: ...` and exits 1 (`src/cli.ts`, test `validate-catalog on a missing or unreadable file ...`). |
| 2 | Writes safe to retry | fixed | A scaffold that failed partway left a half-written `--out`, and re-running then failed with "already written". Files are now rendered into a sibling staging folder and renamed into `--out` only when every step succeeded; a non-empty `--out` is refused up front (`src/scaffold.ts`, two tests in `scaffold.test.ts`). |
| 3 | No race conditions | N/A | Single-threaded synchronous CLI; no shared mutable state. |
| 4 | Don't trust the clock | pass | Durations use `performance.now` (`generated.ts`, `measure.ts`). No stored timestamps. |
| 5 | Read before changing | pass | Only `TMP`/`TMPDIR` are read (temp folder for tests and `measure`). Every relative link in the docs exists. |
| 6 | Never break compatibility | pass | The template and CLI flags are unchanged. One behaviour is stricter: `--out` must be missing or empty (documented in the README). |
| 7 | One source of truth | pass | Node 24 in `engines`, CI and docs; Go 1.26.10 in CI and results. |
| 8 | Small changes, no secrets, validate input | pass | Secret grep: nothing. Form values go through the template's JSON Schema with strict patterns (ADR 0003); CLI usage errors exit 2. No new dependency. |
| 9 | Tests that can actually fail | fixed | No tautologies or unexplained skips (generated-service tests skip only when that toolchain is missing, with the reason). 9/10 mutants killed before, 10/10 after. |
| 10 | Re-verify | pass | Results below; CI on push. |
